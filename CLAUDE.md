# Notes for Claude Code

## The branch

Work on the branch `experimental`, and push your work to it. The owner of
this project asks for this.

A session can start on a different branch, for example a branch with a name
that starts with `claude/`. In that case, change to `experimental` before the
first change. If that branch has commits that are not on `experimental`, bring
them to `experimental` first.

Push to a different branch only when the owner asks for it.
